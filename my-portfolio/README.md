# John Dehree M. Lo Portfolio

This is a responsive personal portfolio website built with HTML5, CSS3, and vanilla JavaScript.

## Project Structure

```text
my-portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
├── assets/
│   ├── profile.jpg
│   ├── resume.pdf
│   └── projects/
│       ├── wellnest.png
│       └── banana-app.png
```

## Run the site

Because this project is static, you can open `index.html` directly in a browser. It is also compatible with GitHub Pages.

## Replace placeholder assets

The following files currently use placeholder assets and should be replaced with your own content when available:

- `assets/profile.jpg` — replace with your profile photo.
- `assets/resume.pdf` — replace with your actual resume PDF.
- `assets/projects/wellnest.png` — replace with a project screenshot or graphic.
- `assets/projects/banana-app.png` — replace with a project screenshot or graphic.

## Notes

- The design uses a dark modern developer theme.
- Navigation includes smooth scrolling and a mobile hamburger menu.
- The project is ready for deployment on GitHub Pages.
